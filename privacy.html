Privacy Policy

Last updated: September 27, 2026

This page covers personal OAuth integrations used by Jarrell Hibler (the “Operator”) to read the Operator’s own account data into private admin tools.

What we access

Depending on the connected service (for example Oura), tools may request read access to wellness metrics such as sleep, readiness, and activity summaries that the Operator already stores with that provider.

How it is used

Data is used only for the Operator’s personal admin checklists and summaries. It is not sold, not used for advertising, and not shared with third parties except as required to run the integration (the provider’s API and the Operator’s private tools).

Storage

Tokens and temporary API responses may be stored on the Operator’s private systems. Health details are not published. This is not a public product and has no end users other than the Operator.

Contact

Questions: use the email on the OAuth application registration for this integration.
